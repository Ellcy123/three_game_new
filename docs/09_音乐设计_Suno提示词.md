# 《三兄弟的冒险2》音乐设计 - Suno提示词

## 整体设计理念

### 统一性策略

为避免五首曲目风格割裂，采用以下统一元素：

| 统一元素 | 说明 |
|---------|------|
| **核心乐器** | 钢琴贯穿全程，作为情感锚点 |
| **氛围层** | 电子环境音（Ambient Synth）营造神秘感 |
| **情感层** | 弦乐在关键时刻加入，增强情感张力 |
| **调性** | 倾向小调，带有淡淡忧伤但不绝望 |
| **节奏** | 避免过于激烈的打击乐，保持沉浸感 |

### 情感曲线

```
密室(神秘) → 藏匿(紧张) → 海龟汤(空灵) → 人物剧情(温暖) → BOSS战(史诗)
   ↓            ↓            ↓             ↓              ↓
  探索         心跳          回忆          成长           决战
```

## 1. 密室 - Escape Room Theme

### Suno提示词

```
[Style]
mysterious piano, ambient electronic, cinematic suspense, puzzle game soundtrack, dark atmospheric, subtle tension, ethereal pads

[Mood]
curious, mysterious, slightly unsettling, exploratory

[Tempo]
slow to medium (70-90 BPM)

[Instruments]
piano, ambient synth pads, subtle strings, soft percussion
```

**完整提示词（可直接使用）：**
```
mysterious piano, ambient electronic, cinematic suspense, puzzle game soundtrack, dark atmospheric, ethereal pads, slow tempo, instrumental, no vocals
```

### 中文解读

**曲风描述**：神秘钢琴 + 电子氛围音 + 电影悬疑感

这首曲子以**若隐若现的钢琴**为主导，配合**空灵的合成器垫音**，营造出"被困密室"的压迫感和解谜时的专注氛围。音乐不会太恐怖，而是带有一种"好奇心驱动"的探索感。

### 为什么是这个曲风

| 场景需求 | 音乐对应 |
|---------|---------|
| 玩家醒来被困 | 神秘氛围，不知身处何处 |
| 解谜探索 | 钢琴音符如同线索，引导思考 |
| 悬疑但不恐怖 | 柔和的电子音避免jump scare感 |
| 需要长时间聆听 | 慢节奏不会造成疲劳 |

## 2. 藏匿 - Hiding Theme

### Suno提示词

```
[Style]
tense ambient, heartbeat rhythm, stealth game music, quiet suspense, minimalist electronic, breath-holding tension, soft pulsing bass

[Mood]
anxious, alert, holding breath, fear of being discovered

[Tempo]
slow with pulsing rhythm (60-80 BPM)

[Instruments]
low synth bass, subtle heartbeat percussion, sparse piano notes, tense strings
```

**完整提示词（可直接使用）：**
```
tense ambient, heartbeat rhythm, stealth game music, quiet suspense, minimalist electronic, pulsing bass, sparse piano, instrumental, no vocals
```

### 中文解读

**曲风描述**：紧张氛围 + 心跳节奏 + 潜行游戏音乐

这首曲子以**低沉的脉冲低音**模拟心跳，配合**稀疏的钢琴音符**，营造出"屏住呼吸等待危险过去"的紧张感。音乐极简，留出大量空白，让玩家能听到游戏中的脚步声等音效。

### 为什么是这个曲风

| 场景需求 | 音乐对应 |
|---------|---------|
| 躲避兜帽男 | 心跳节奏增强紧张感 |
| 不能被发现 | 极简音乐不干扰判断 |
| 需要专注聆听脚步 | 留白设计让音效突出 |
| 承接密室氛围 | 延续钢琴+电子音色 |

## 3. 海龟汤 - Memory Recall Theme

### Suno提示词

```
[Style]
ethereal piano, melancholic ambient, dreamy atmospheric, nostalgic soundtrack, bittersweet melody, gentle reverb, memory flashback music

[Mood]
reflective, sad but beautiful, dreamlike, nostalgic

[Tempo]
slow and flowing (55-70 BPM)

[Instruments]
reverbed piano, warm synth pads, soft strings, gentle chimes
```

**完整提示词（可直接使用）：**
```
ethereal piano, melancholic ambient, dreamy atmospheric, nostalgic bittersweet, gentle reverb, memory flashback, warm strings, instrumental, no vocals
```

### 中文解读

**曲风描述**：空灵钢琴 + 忧郁氛围 + 梦境般的回忆感

这首曲子以**带混响的钢琴**为核心，音符仿佛从遥远的记忆中飘来。配合**温暖的弦乐**，营造出"回忆涌上心头"的感觉。曲调忧伤但不绝望，有一种"美丽的悲伤"。

### 为什么是这个曲风

| 场景需求 | 音乐对应 |
|---------|---------|
| 记忆回溯 | 梦境般的混响效果 |
| 揭示三只宠物的死亡 | 忧伤但不压抑 |
| 情感高潮（汤底揭示） | 温暖弦乐增强共情 |
| 承接前两关 | 钢琴主导保持统一 |

## 4. 人物剧情 - Character Story Theme

### Suno提示词

```
[Style]
soft playful piano, gentle cheerful, light whimsical, delicate happy melody, relaxed joyful, mellow cute, cozy background music

[Mood]
gentle joy, soft happiness, relaxed playful, carefree calm

[Tempo]
slow to medium, steady (70-85 BPM)

[Instruments]
soft piano, gentle pizzicato strings, music box, light glockenspiel, quiet woodwinds
```

**完整提示词（可直接使用）：**
```
soft playful piano, gentle cheerful, light whimsical, delicate happy, mellow cute, relaxed joyful, music box, lo-fi calm, instrumental, no vocals
```

### 中文解读

**曲风描述**：轻柔俏皮钢琴 + 温柔欢快 + 小小的幸福感

这首曲子以**轻声细语般的钢琴**为主导，配合**音乐盒音色**和**柔和的拨弦**，营造出"小确幸"的感觉。音量始终保持轻柔，没有起伏高潮，像午后阳光下的悠闲时光。

### 为什么是这个曲风

| 场景需求 | 音乐对应 |
|---------|---------|
| 长时间阅读剧情 | 轻柔不干扰，适合循环 |
| 欢乐但不激烈 | 小声的快乐，温馨舒适 |
| 背景陪伴感 | 不抢戏，安静陪伴 |
| 情感调剂 | 从忧伤转向轻松愉悦 |

```
focused adventure, determined rhythm, steady energy, motivating game music, light heroic, warm action theme, gentle drive

[Mood]
focused, determined but warm, steady motivation, calm energy

[Tempo]

[Instruments]

```

**完整提示词（可直接使用）：**
```
focused adventure, determined rhythm, steady energy, motivating game music, light heroic, warm action, gentle drive, piano, instrumental, no vocals
```

### 中文解读

**曲风描述**：专注冒险 + 稳定节奏 + 温暖的干劲

这首曲子以**稳定的节奏**和**温暖的弦乐**营造"认真挑战"的氛围。不紧张也不嬉闹，像是"好，我们来认真对付它"的感觉。有干劲但很从容。

### 为什么是这个曲风

| 场景需求 | 音乐对应 |
|---------|---------|
| 三场BOSS战 | 专注但不焦虑 |
| 需要思考策略 | 稳定节奏帮助专注 |
| 团队协作 | 温暖感代表团结 |
| 介于紧张和欢乐之间 | 平衡的能量感 |
| 保持统一性 | 钢琴呼应全曲 |

## Suno使用建议

### 生成设置

| 参数 | 建议值 |
|------|--------|
| 时长 | 2-3分钟（可循环） |
| 风格 | Instrumental |
| 人声 | No Vocals |

### 统一性技巧

1. **使用相同的Seed**（如果Suno支持）可以让音色更统一
2. **添加关键词 `cohesive soundtrack`** 增强专辑感
3. **在所有提示词中加入 `piano` 关键词**保持乐器统一
4. **避免极端风格词**如 `heavy metal`、`EDM drop` 等

### 循环播放注意

游戏BGM需要循环，生成时可添加：
```
loopable, seamless loop, game background music
```
