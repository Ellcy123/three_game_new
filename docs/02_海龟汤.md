# 《三兄弟的冒险2》游戏策划文档（开发版 v2.0）

## 四、第二幕：海龟汤（记忆回溯）

### 4.1 关卡概述

**关卡名称：** 海龟汤（记忆回溯）

**关卡目标：** 通过提问揭示三只动物的真实身份和死因

**关卡类型：** 推理问答关卡

**预计时长：** 10-20分钟

**关卡特性：**
- ✅ 交织叙事：三个故事混合在同一段题干中
- ✅ 点击提问：点击关键词选择问题，获得YES/NO答案
- ✅ 资源管理：每人10次免费提问，超出消耗生命值
- ✅ 推理挑战：需要拆解三个故事，找出真相
- ✅ 团队协作：三人共同推理，分享线索

**前置条件：** 第二关（藏匿）已通关

**核心谜题：**
- 任务1：找到三因（三个角色各自的死因）
- 任务2：找到身份（发现他们不是人类，而是三只宠物）

#### 4.6.2 提问阶段详解

**阶段流程：**

```
步骤1：显示题干
    题干中的关键词高亮显示
    显示每个玩家的剩余提问次数

步骤2：玩家点击关键词
    IF 该关键词尚未被点击过:
        弹出问题选择面板
    ELSE:
        显示提示："该词语已被提问过"
        显示之前选择的问题和答案

步骤3：选择问题
    显示3个问题选项
    玩家选择其中1个

步骤4：消耗提问次数
    IF 玩家.免费提问次数 > 0:
        玩家.免费提问次数 -= 1
    ELSE:
        玩家.生命值 -= 1
        玩家.额外提问次数 += 1
        显示提示："消耗1点生命值进行提问"

步骤5：显示答案
    显示 YES 或 NO
    记录该关键词已被提问
    记录选择的问题和答案（供回顾）

步骤6：继续或提交
    玩家可以继续点击其他关键词
    或点击【提交答案】进入下一阶段
```

#### 4.6.4 答案判定逻辑

```javascript
function judgeAnswers(answers, players) {
    let results = {
        question1: false,
        question2: false,
        question3: [false, false, false]
    };

    // 问题1判定：死亡人数
    if (answers.deathCount === 3) {
        results.question1 = true;
    } else {
        // 答错，每人扣1血
        players.forEach(p => p.hp -= 1);
        showMessage("答案错误！正确答案是3个角色死亡。每人生命值-1");
    }

    // 问题2判定：是否人类
    if (answers.isHuman === false) {
        results.question2 = true;
    } else {
        // 答错，每人扣1血
        players.forEach(p => p.hp -= 1);
        showMessage("答案错误！你们不是人类。每人生命值-1");
    }

    // 问题3判定：身份选择
    const correctIdentities = ['猫', '狗', '龟'];
    for (let i = 0; i < 3; i++) {
        if (answers.identities[i] === correctIdentities[i]) {
            results.question3[i] = true;
        } else {
            // 对应玩家扣1血
            players[i].hp -= 1;
            showMessage(`${players[i].name}的答案错误！生命值-1`);
        }
    }

    return results;
}
```

### 4.10 特殊情况处理

#### 4.10.1 提问次数耗尽

```
IF 玩家.免费提问次数 == 0:
    显示提示："免费提问次数已用完"
    显示选项：
        A. 消耗1点生命值继续提问
        B. 放弃提问

    IF 选择A AND 玩家.生命值 > 1:
        玩家.生命值 -= 1
        允许继续提问
    ELSE IF 选择A AND 玩家.生命值 <= 1:
        显示提示："生命值不足，无法继续提问"
```

#### 4.10.2 玩家掉线处理

```
IF 玩家在提问阶段掉线:
    该玩家的提问权限暂停
    其他玩家可继续提问

IF 玩家在答案提交阶段掉线:
    该玩家由系统随机选择答案
    显示："<玩家名>（托管中）随机选择了答案"

IF 玩家重新连接:
    恢复玩家控制
    显示当前游戏状态和已有的问答记录
```

#### 4.10.3 关键词重复点击

```
IF 关键词已被提问:
    显示该关键词之前选择的问题和答案
    不允许重新选择问题
    不消耗提问次数
```

#### 4.10.4 生命值归零

```
IF 玩家生命值 <= 0:
    // 本关卡仍有保护机制
    玩家生命值 = 1
    显示："<玩家名>感到一阵眩晕，神秘的力量支撑着..."

    // 玩家仍可参与后续流程，但无法再额外提问
```
