### 9.1.3 结局设计理念

```
【结局0】死于鼠鼠大王
  设计意图：惩罚性结局，玩家在第一关BOSS就失败
  情感体验：略带讽刺的失败感
  游戏时长：约30-60分钟即触发

【结局1】疯人院
  设计意图：隐藏反转结局，颠覆整个游戏世界观
  情感体验：荒诞、震惊、细思极恐
  核心创意：双视角叙事（玩家幻想 vs 现实真相）

【结局2】我也永远爱你
  设计意图：真正的情感结局，揭示游戏主题
  情感体验：温情、感动、治愈
  核心创意：宠物对主人的最后告白
```

## 9.3 结局1：疯人院

### 9.3.1 触发条件

```
条件：以下任意情况
  1. 击败鼠鼠大王后，在百变小鹦处失败（三人阵亡）
  2. 击败百变小鹦后，在死神处胜利（筹码超过1000）
  3. 其他非结局0、非结局2的情况
```

### 9.3.2 结局核心概念

```
【反转设定】
  整个游戏的冒险，其实是三位精神病人的集体幻想。
  他们并不是真正的猫、狗、乌龟，而是重度妄想症患者。

【双视角叙事】
  每一幕都用两个视角呈现：
  - 玩家视角：他们眼中的奇幻冒险
  - 护士视角：医院工作人员眼中的真相

【讽刺与温情】
  虽然是"疯人院"结局，但护士的描述中透露出对患者的理解和包容
  三人虽然"疯狂"，但配合默契，关系和谐
```

### 9.3.4 双视角对照表

| 幕 | 玩家眼中 | 现实真相 |
|---|---------|---------|
| 密室 | 被困密室，找到密码ECHO逃出 | 在病房玩耍，把头放进马桶，乱按门锁 |

| 分别 | 分头修炼提升实力 | 各种怪异行为（趴石头、挠东西、闻人） |

| 角色 | 游戏中身份 | 病房中表现 | 对应行为 |
|------|----------|----------|---------|
| 玩家1 | 猫咪 | 舔自己的手 | 猫的本能行为 |
| 玩家2 | 狗狗 | 伸舌头傻笑、到处闻 | 狗的本能行为 |
| 玩家3 | 乌龟 | 扣锅在身上不动、趴石头 | 乌龟的本能行为 |

### 9.3.6 UI设计建议

```
【整体风格】
  - 分屏或切换展示两个视角
  - 玩家视角：奇幻、明亮、冒险风格
  - 护士视角：现实、冷色调、医院风格

【转场效果】
  - 视角切换时使用"闪回"或"镜头模糊"效果
  - 配合音效变化（奇幻音乐 ↔ 现实环境音）

【文字展示】
  - 玩家视角：普通字体，正常展示
  - 护士视角：打字机效果，像在写病历报告

【结局画面】
  - 背景：温馨的病房，三人拿着零食微笑
  - 氛围：虽然是"疯人院"，但传达温暖感
```

## 9.4 结局2：我也永远爱你（真结局）

### 9.4.1 触发条件

```
条件：BOSS战第三关（死神）失败
  - 15轮结束时筹码 ≤ 1000
  - 或筹码归零（无复活技能可用）
  - 或第11轮投出4点死亡（无挽救手段）
```

### 9.4.2 结局核心概念

```
【世界观揭秘】
  这个世界不是被创造出来的，而是因爱形成的"回响空间"。

  宠物去世后，因为主人的念念不忘，在这里产生了回响。
  因此出现了这个由宠物构成的世界。

  密码"ECHO"（回响）正是这个世界的本质。

【主题升华】
  "被思念，所以还存在"

  这是一个关于爱、思念和告别的故事。
  三只宠物虽然已经离开，但在主人的思念中永远存在。

【情感高潮】
  三只动物通过异世界的冒险者，向主人传达最后的话语。
  这是迟来的告别，也是永恒的爱。
```

### 9.4.3 完整结局剧情

---


### 9.5.2 伪代码实现

```typescript
enum Ending {
  ENDING_0 = 'DEATH_BY_MOUSE_KING',  // 死于鼠鼠大王
  ENDING_1 = 'ASYLUM',                // 疯人院
  ENDING_2 = 'I_LOVE_YOU_TOO'         // 我也永远爱你
}

function determineEnding(gameState: GameState): Ending {
  // 检查BOSS战结果
  const boss1Result = gameState.boss1_MouseKing;
  const boss2Result = gameState.boss2_Parrot;
  const boss3Result = gameState.boss3_Death;

  // 第一关失败 → 结局0
  if (boss1Result === 'LOSE') {
    return Ending.ENDING_0;
  }

  // 第二关失败 → 结局1
  if (boss2Result === 'LOSE') {
    return Ending.ENDING_1;
  }

  // 第三关失败 → 结局2（真结局）
  if (boss3Result === 'LOSE') {
    return Ending.ENDING_2;
  }

  // 第三关胜利 → 结局1
  if (boss3Result === 'WIN') {
    return Ending.ENDING_1;
  }

  // 默认（不应该到达这里）
  return Ending.ENDING_1;
}

function playEnding(ending: Ending): void {
  switch (ending) {
    case Ending.ENDING_0:
      playEnding0_DeathByMouseKing();
      break;
    case Ending.ENDING_1:
      playEnding1_Asylum();
      break;
    case Ending.ENDING_2:
      playEnding2_ILoveYouToo();
      break;
  }
}
```
