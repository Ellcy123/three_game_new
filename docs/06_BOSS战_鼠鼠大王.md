# 06_BOSS战_鼠鼠大王

## 6.1 BOSS信息

### 基础属性

| 属性 | 值 |
|------|-----|
| 名称 | 鼠鼠大王 |
| 生命值 | 6 |
| 关卡序号 | 第一关（BOSS战） |
| 出战方式 | 单人轮流出战 |
| 胜利条件 | BOSS生命值归零 |
| 失败条件 | 三人全部阵亡 |
| 失败结局 | 结局0：死于鼠鼠大王 |

### 背景故事

> 原本是一只宠物仓鼠，刚来到这个世界受尽了欺负，因此经常挖洞躲在地下。久而久之，凭借着自己的努力，建立了地下世界，常年生活在地下八英尺左右的位置，现在是 underground 的 king，万鼠膜拜。

### 战斗开场文案

> 鼠鼠大王拥有良好的教养，并不会使用暴力。他在你们面前挖了五个大洞，每个洞都有鼠鼠大王珍藏的道具与陷阱，鼠鼠大王也藏在其中，请选择洞口进行攻击。
>
> 请选择一人参战。（死亡后换人出战）

### 战斗触发文案

> 其他两位笨蛋玩家不小心陷入洞中，请小心误伤队友。

## 6.2 出战规则

### 6.2.1 基础规则

- **单人出战**：每次只能一名玩家参战
- **轮换机制**：当前出战玩家阵亡后，由下一名玩家接替
- **出战顺序**：玩家自行决定出战顺序
- **胜利判定**：BOSS生命值归零时，战斗胜利
- **失败判定**：三名玩家全部阵亡时，战斗失败

### 6.2.2 角色出战效果

| 角色 | 效果名称 | 效果描述 | 备注 |
|------|---------|---------|------|
| 猫 | 天敌克制 | 对鼠鼠大王伤害 **+1** | 基础伤害1→2 |
| 狗 | 多管闲事 | 本关卡 **不允许** 狗玩家出战 | 其余玩家全部阵亡后失效 |
| 龟 | 师傅压制 | 对鼠鼠大王伤害 **减半**（向下取整） | 基础伤害1→0.5→0 |

### 6.2.3 出战优先级说明

```
正常情况：
  猫（推荐）> 龟 > 狗（禁止）

特殊情况（猫、龟均阵亡）：
  狗可以出战（多管闲事效果解除）
```

### 6.2.4 伤害计算公式

```
最终伤害 = (基础伤害 + 技能加成) × 角色系数

角色系数：
  - 猫：1.0（额外+1伤害在技能加成中计算）
  - 狗：1.0
  - 龟：0.5（向下取整，最低为0）

示例：
  - 猫出战，无技能：(1 + 1) × 1.0 = 2
  - 龟出战，无技能：1 × 0.5 = 0.5 → 0（向下取整）
  - 龟出战，岩浆炮（基础伤害2）：2 × 0.5 = 1
```

## 6.3 洞口机制

### 6.3.1 洞口内容表

| 代号 | 名称 | 效果描述 | 伤害类型 |
|------|------|---------|---------|
| A | 鼠鼠大王 | 命中BOSS，BOSS生命值 **-1**（受加成影响） | 对BOSS伤害 |
| B | 巧克力酱 | 猫、狗误食，猫和狗生命值各 **-1** | 对队友伤害 |
| C | 囤货区 | 发现食物储藏室，全体生命值 **+1** | 回复效果 |
| D | 狗 | 误伤被困的狗，狗生命值 **-1**（受加成影响） | 对队友伤害 |
| E | 龟/猫 | 误伤队友，龟或猫生命值 **-1**（受加成影响） | 对队友伤害 |

### 6.3.2 洞口分配规则

1. **随机分配**：主持人/系统将 A、B、C、D、E 随机分配到洞口 1-5
2. **每轮重置**：每回合结束后，重新随机分配
3. **玩家不可见**：玩家只能看到洞口编号（1-5），无法看到内容（A-E）

### 6.3.3 分配示例

```
第一回合：
  洞口1: C（囤货区）
  洞口2: D（狗）
  洞口3: A（鼠鼠大王）
  洞口4: B（巧克力酱）
  洞口5: E（龟/猫）

第二回合（重新随机）：
  洞口1: B（巧克力酱）
  洞口2: A（鼠鼠大王）
  洞口3: E（龟/猫）
  洞口4: C（囤货区）
  洞口5: D（狗）
```

### 6.3.4 洞口E的特殊规则

洞口E的受害者取决于当前 **未出战** 的角色：

| 出战角色 | E的受害者 | 说明 |
|---------|----------|------|
| 猫 | 龟 | 狗被困洞中（D位置），龟在场外 |
| 龟 | 猫 | 狗被困洞中（D位置），猫在场外 |
| 狗 | 猫或龟（随机） | 特殊情况，猫龟均阵亡时 |

### 6.4.2 详细步骤

#### 步骤1：战斗开始前检查

```
1. 检查是否有【慈悲之心】技能
   → 若有，直接跳过第一关卡，进入第二关

2. 检查是否有【任意门】道具
   → 若使用，可选择从任意关卡开始

3. 检查是否有【丘比特之箭】道具
   → 若使用，本关卡免疫所有伤害

4. 应用战斗开始时的技能效果
   → 【拷贝】：生命值同步为最高者
   → 【黑暗料理】：BOSS生命值-1（无法加成）
```

#### 步骤2：选择出战玩家

```
1. 玩家选择出战角色

2. 检查出战限制：
   IF 选择狗 AND (猫存活 OR 龟存活):
     提示"多管闲事，狗不可出战"
     重新选择

3. 检查联合出战技能：
   → 【创意工坊】【呼朋沟友】【花瓶？哼！】【挥金如土】
   → 若有，允许多人同时出战

4. 应用出战角色的被动效果
```

#### 步骤3：洞口选择阶段

```
1. 系统随机分配 A-E 到洞口 1-5

2. 检查洞口排除技能：
   → 【义眼】：排除B（巧克力）和D（狗）洞口，告知玩家
   → 【破绽追击】【识人阁】【火箭靴】【读心术】：减少1个错误洞口

3. 玩家选择洞口编号

4. 检查多选技能：
   → 【借力打力】【召唤学生会】【一万伏特】：可选2个洞口
   → 【高压水炮】：可对同一洞口攻击3次
```

#### 步骤4：结算阶段

```
1. 揭示洞口内容

2. 根据内容执行效果：
   CASE A（鼠鼠大王）:
     计算伤害 = 基础伤害 + 技能加成
     检查【居合】→ 秒杀
     应用角色系数（龟减半）
     BOSS生命值 -= 最终伤害

   CASE B（巧克力酱）:
     检查【心如止水】→ 免疫
     检查【刀风之盾】→ 对龟无效
     猫生命值 -= 1
     狗生命值 -= 1

   CASE C（囤货区）:
     全体生命值 += 1

   CASE D（狗）:
     计算伤害 = 基础伤害 + 技能加成
     狗生命值 -= 最终伤害

   CASE E（龟/猫）:
     确定受害者
     计算伤害 = 基础伤害 + 技能加成
     受害者生命值 -= 最终伤害

3. 检查伤害触发的技能：
   → 【舆论的力量】：50%概率无效化伤害
   → 【最高龟格】：50%概率减免伤害
   → 【碧落黄泉】：50%伤害翻倍吸收 / 50%转移给BOSS
   → 【恃宠而骄】：自己受伤时，所有人和BOSS受同等伤害
   → 【五雷法】：自己被击中时，其他所有人（包括BOSS）生命值-1
   → 【治愈系水枪】：受伤时指定队友+1生命值

4. 检查阵亡触发的技能：
   → 【忍者勋章】：50%概率不死
   → 【竹蜻蜓】：躲避一次致命伤害
   → 【第二引擎】：50%概率20生命值复活
   → 【妻子登场】：阵亡时判定，奇数+2生命值，循环直到偶数
   → 【超音速急行】：1/6概率被击中（即5/6概率闪避）
```

#### 步骤5：回合结束检查

```
1. BOSS生命值检查：
   IF BOSS生命值 <= 0:
     战斗胜利，进入第二关

2. 玩家状态检查：
   IF 三人全部阵亡:
     战斗失败，触发结局0

   IF 当前出战玩家阵亡:
     换人出战（玩家选择或按顺序）

3. 进入下一回合
```

### 6.5.2 技能冲突处理

#### 处理原则

1. **按获得顺序触发**：同类型技能按玩家获得的先后顺序依次触发
2. **跳关优先**：【慈悲之心】等跳关技能最优先
3. **免疫 > 减免 > 转移**：伤害处理的优先级
4. **死亡判定最后**：先处理所有伤害减免，再判定是否阵亡

#### 冲突示例

```
场景1：同时拥有【舆论的力量】和【最高龟格】
  → 按获得顺序依次判定
  → 第一个技能生效则伤害处理完毕
  → 第一个技能未生效则判定第二个

场景2：【恃宠而骄】和【五雷法】同时存在
  → 龟受伤时触发【恃宠而骄】→ 所有人和BOSS受伤
  → 狗被【恃宠而骄】击中 → 触发【五雷法】→ 其他人和BOSS再-1
  → 可能产生连锁反应

场景3：【居合】和伤害加成技能
  → 【居合】效果为"秒杀"，直接将BOSS生命值清零
  → 伤害加成技能不再计算
```

## 6.7 判定逻辑伪代码

### 6.7.1 战斗主循环

```typescript
interface BattleState {
  bossHp: number;           // BOSS生命值
  players: Player[];        // 玩家列表
  currentPlayer: Player;    // 当前出战玩家
  round: number;            // 当前回合
  holeContents: string[];   // 洞口内容 [A,B,C,D,E] 对应洞口 [1,2,3,4,5]
}

function startBossBattle_MouseKing(): BattleResult {
  // 初始化
  const state: BattleState = {
    bossHp: 6,
    players: [cat, dog, turtle],
    currentPlayer: null,
    round: 0,
    holeContents: []
  };

  // 战斗开始前检查
  if (hasSkill('慈悲之心')) {
    return { result: 'SKIP', nextStage: 'BOSS_2' };
  }

  if (hasItem('任意门') && playerChooseToUse()) {
    return { result: 'SKIP', nextStage: playerChooseStage() };
  }

  // 应用战斗开始技能
  applyBattleStartSkills(state);

  // 选择出战玩家
  state.currentPlayer = chooseFirstPlayer(state);

  // 主循环
  while (true) {
    state.round++;

    // 随机分配洞口
    state.holeContents = shuffleHoles(['A', 'B', 'C', 'D', 'E']);

    // 应用洞口排除技能
    const excludedHoles = applyHoleExclusionSkills(state);

    // 玩家选择洞口
    const selectedHoles = playerSelectHoles(state, excludedHoles);

    // 执行攻击
    for (const hole of selectedHoles) {
      executeHoleEffect(state, hole);
    }

    // 检查战斗结束
    if (state.bossHp <= 0) {
      applyBattleEndSkills(state);
      return { result: 'WIN', nextStage: 'BOSS_2' };
    }

    if (allPlayersDead(state)) {
      return { result: 'LOSE', ending: 'ENDING_0' };
    }

    // 检查换人
    if (state.currentPlayer.hp <= 0) {
      state.currentPlayer = chooseNextPlayer(state);
    }
  }
}
```

### 6.7.2 洞口效果执行

```typescript
function executeHoleEffect(state: BattleState, holeIndex: number): void {
  const content = state.holeContents[holeIndex - 1];

  switch (content) {
    case 'A': // 鼠鼠大王
      handleHitBoss(state);
      break;

    case 'B': // 巧克力酱
      handleChocolate(state);
      break;

    case 'C': // 囤货区
      handleFoodStorage(state);
      break;

    case 'D': // 狗
      handleHitDog(state);
      break;

    case 'E': // 龟/猫
      handleHitOther(state);
      break;
  }
}

function handleHitBoss(state: BattleState): void {
  // 检查秒杀
  if (hasSkill('居合') && state.currentPlayer.type === 'TURTLE') {
    state.bossHp = 0;
    showMessage('居合斩！秒杀鼠鼠大王！');
    return;
  }

  // 检查海龟汤
  if (hasSkill('海龟汤') && playerChooseToUse()) {
    const roll = rollDice();
    if (roll <= 3) {
      state.bossHp = 0;
      showMessage('海龟汤命中汤底！直接获胜！');
      return;
    } else {
      state.currentPlayer.hp = 0;
      state.currentPlayer.canRevive = false;
      showMessage('海龟汤未命中...水炮龟阵亡且不可复活');
      return;
    }
  }

  // 计算伤害
  let damage = getBaseDamage(state.currentPlayer);
  damage += getDamageBonus(state.currentPlayer);
  damage = applyCharacterModifier(state.currentPlayer, damage);

  state.bossHp -= damage;
  showMessage(`命中鼠鼠大王！造成 ${damage} 点伤害`);
}

function handleChocolate(state: BattleState): void {
  const cat = state.players.find(p => p.type === 'CAT');
  const dog = state.players.find(p => p.type === 'DOG');

  // 猫受伤检查
  if (cat && cat.hp > 0) {
    if (hasSkill('心如止水', cat)) {
      showMessage('心如止水：猫免疫巧克力伤害');
    } else {
      applyDamage(cat, 1, state);
    }
  }

  // 狗受伤
  if (dog && dog.hp > 0) {
    applyDamage(dog, 1, state);
  }
}

function applyDamage(target: Player, baseDamage: number, state: BattleState): void {
  let damage = baseDamage;

  // 检查免疫
  if (checkImmunity(target, damage)) {
    return;
  }

  // 检查概率减免
  if (hasSkill('舆论的力量', target)) {
    if (rollDice() <= 3) {
      showMessage('舆论的力量：伤害无效化！');
      return;
    }
  }

  if (hasSkill('最高龟格', target)) {
    if (rollDice() <= 3) {
      showMessage('最高龟格：敌人手下留情，伤害减免！');
      return;
    }
  }

  if (hasSkill('碧落黄泉', target)) {
    if (rollDice() <= 3) {
      target.hp += damage * 2;
      showMessage(`碧落黄泉：伤害翻倍吸收！生命值+${damage * 2}`);
      return;
    } else {
      state.bossHp -= damage;
      showMessage(`碧落黄泉：伤害转移给BOSS！BOSS生命值-${damage}`);
      return;
    }
  }

  if (hasSkill('超音速急行', target)) {
    if (rollDice() !== 1) { // 只有1点才命中
      showMessage('超音速急行：闪避成功！');
      return;
    }
  }

  // 应用伤害
  target.hp -= damage;

  // 检查连锁效果
  if (hasSkill('恃宠而骄', target)) {
    for (const player of state.players) {
      if (player !== target) {
        player.hp -= damage;
      }
    }
    state.bossHp -= damage;
    showMessage('恃宠而骄：所有人和BOSS受到同等伤害！');
  }

  if (hasSkill('五雷法', target)) {
    for (const player of state.players) {
      if (player !== target) {
        player.hp -= 1;
      }
    }
    state.bossHp -= 1;
    showMessage('五雷法：天雷降临！所有人和BOSS生命值-1！');
  }

  if (hasSkill('治愈系水枪', target)) {
    const healTarget = playerChooseHealTarget(state);
    healTarget.hp += 1;
    showMessage(`治愈系水枪：${healTarget.name}生命值+1`);
  }

  // 检查阵亡
  if (target.hp <= 0) {
    handleDeath(target, state);
  }
}

function handleDeath(target: Player, state: BattleState): void {
  // 检查免死技能
  if (hasSkill('忍者勋章', target)) {
    if (rollDice() <= 3) {
      target.hp = 1;
      showMessage('忍者勋章：不屈意志，拒绝死亡！');
      return;
    }
  }

  if (hasItem('竹蜻蜓', target) && !target.usedBamboo) {
    target.hp = 1;
    target.usedBamboo = true;
    showMessage('竹蜻蜓：躲避致命伤害！');
    return;
  }

  if (hasSkill('第二引擎', target)) {
    if (rollDice() <= 3) {
      target.hp = 20;
      showMessage('第二引擎：复活！生命值恢复至20！');
      return;
    }
  }

  if (hasSkill('妻子登场', target)) {
    let roll = rollDice();
    while (roll % 2 === 1) { // 奇数
      target.hp += 2;
      showMessage(`妻子登场：奇数！生命值+2，当前${target.hp}`);
      roll = rollDice();
    }
    if (target.hp > 0) {
      showMessage('妻子登场：偶数，判定结束');
      return;
    }
  }

  // 确认阵亡
  target.isDead = true;
  showMessage(`${target.name} 阵亡！`);
}
```

### 6.7.3 工具函数

```typescript
function shuffleHoles(contents: string[]): string[] {
  // Fisher-Yates 洗牌算法
  const result = [...contents];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}

function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1; // 1-6
}

function getBaseDamage(player: Player): number {
  // 检查基础伤害提升技能
  if (hasSkill('岩浆炮', player)) return 2;
  if (hasSkill('花瓶？哼！', player) && hasMultiplePlayerSkill()) return 4;
  return 1;
}

function getDamageBonus(player: Player): number {
  let bonus = 0;

  // 角色固有加成
  if (player.type === 'CAT') bonus += 1; // 天敌克制

  // 技能加成
  if (hasSkill('喵喵叫', player)) bonus += 1;
  if (hasSkill('鼠类克星', player)) bonus += 1;
  if (hasSkill('泼水', player)) bonus += 1;

  return bonus;
}

function applyCharacterModifier(player: Player, damage: number): number {
  if (player.type === 'TURTLE') {
    return Math.floor(damage * 0.5); // 师傅压制，减半向下取整
  }
  return damage;
}

function chooseFirstPlayer(state: BattleState): Player {
  // 显示选择界面，狗不可选（除非其他人已阵亡）
  const availablePlayers = state.players.filter(p => {
    if (p.type === 'DOG') {
      return state.players.filter(other =>
        other.type !== 'DOG' && other.hp > 0
      ).length === 0;
    }
    return p.hp > 0;
  });

  return playerSelect(availablePlayers);
}
```
