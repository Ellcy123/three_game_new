# 《三兄弟的冒险2》游戏策划文档（开发版 v2.0）

## 三、第一幕 - 第二关：藏匿

### 3.1 关卡概述

**关卡名称：** 藏匿

**关卡目标：** 躲避黑色兜帽男的5次攻击，尽可能保存生命值

**关卡类型：** 生存躲避关卡

**预计时长：** 3-5分钟

**关卡特性：**
- ✅ 实时互动：三名玩家可以看到彼此的选择
- ✅ 随机攻击：系统随机选择攻击区域
- ✅ 区域摧毁：被攻击的区域将被摧毁，不可再次使用
- ✅ 生存奖励：全程未被击中的玩家获得额外奖励

**前置条件：** 第一关（密室）已通关

**选择阶段逻辑：**

```
阶段开始：
    初始化倒计时 = 15秒
    所有玩家选择状态 = 未选择

WHILE 倒计时 > 0 AND 存在未确认的玩家:

    FOR 每个玩家:
        显示可用区域列表（排除已摧毁区域）
        显示每个区域当前人数
        显示队友实时选择（实时更新）

    IF 玩家点击区域:
        IF 该区域已摧毁:
            显示提示："该区域已被摧毁，请选择其他区域"
            CONTINUE

        IF 该区域当前人数 >= 2:
            显示提示："该区域已满（2/2），请选择其他区域"
            CONTINUE

        更新玩家选择 = 该区域
        广播给所有玩家（实时显示）

    IF 玩家点击确认:
        锁定该玩家选择
        显示"已确认，等待其他玩家..."

    倒计时 -= 1秒

阶段结束：
    FOR 每个未确认选择的玩家:
        IF 玩家已选择但未确认:
            使用当前选择
        ELSE:
            从可用区域中随机分配
            显示："<玩家名>慌乱中躲进了【随机区域】"
```

**容量冲突处理：**

由于玩家可以实时看到队友选择，正常情况下不会出现3人选同一区域的情况。

但如果出现边界情况（如同时点击）：
```
IF 区域选择人数 > 2:
    按确认时间排序
    保留前2名玩家
    第3名玩家:
        取消选择
        显示提示："区域已满！请重新选择"
        IF 倒计时已结束:
            随机分配到其他可用区域
            显示："<玩家名>被挤出，慌乱中躲进了【随机区域】"
```

#### 3.4.3 攻击阶段详解

**阶段流程：**

```
步骤1：生成攻击目标
    从【可用区域列表】中随机选择1个区域
    attackTarget = random(可用区域列表)

步骤2：攻击预告（制造紧张感）
    显示文本："黑色兜帽男举起了武器..."
    等待 1.5 秒

步骤3：攻击动画
    显示文本："他朝着【{attackTarget}】挥出了致命一击！"
    播放攻击特效/动画
    等待 1 秒

步骤4：判定结果
    hitPlayers = 获取该区域内的所有玩家

    IF hitPlayers.length > 0:
        FOR 每个被击中的玩家:
            玩家.生命值 -= 1
            玩家.被击中次数 += 1
            显示："💥 <玩家名>被击中了！生命值 -1"

        显示攻击成功动画
    ELSE:
        显示："兜帽男扑了个空..."
        显示攻击落空动画

步骤5：区域摧毁
    attackTarget.状态 = 已摧毁
    显示："【{attackTarget}】被摧毁了，无法再使用"
    从可用区域列表中移除该区域
```

### 3.6 奖惩规则

#### 3.6.1 伤害规则

| 情况 | 生命值变化 | 说明 |
|------|-----------|------|
| 被攻击击中 | -1 | 每次被击中扣1点 |
| 同一轮多人被击中 | 每人各-1 | 同区域多人都会受伤 |

#### 3.6.2 奖励规则

| 条件 | 奖励 | 说明 |
|------|------|------|
| 5轮全部躲过（被击中次数=0） | 生命值+3 | 单独计算，每个符合条件的玩家都能获得 |

#### 3.6.3 奖励判定逻辑

```
游戏结束时：
    FOR 每个玩家:
        IF 玩家.被击中次数 == 0:
            玩家.生命值 += 3
            显示特效："🎉 完美躲避！"
            显示文本："<玩家名>全程躲过了所有攻击！生命值 +3"
```

### 3.9 特殊情况处理

#### 3.9.1 玩家掉线处理

```
IF 玩家在选择阶段掉线:
    该玩家由系统AI托管
    AI随机选择一个可用区域
    显示："<玩家名>（托管中）躲进了【随机区域】"

IF 玩家重新连接:
    恢复玩家控制
    显示当前游戏状态
```

#### 3.9.2 所有区域都满的边界情况

理论上不会发生（3人，每区域2人容量，至少4个可用区域）

```
IF 所有可用区域都满（极端边界情况）:
    允许玩家选择已有1人的区域
    显示提示："所有区域都很拥挤，请选择一个区域挤一挤"
```

#### 3.9.3 玩家生命值归零

```
IF 玩家生命值 <= 0:
    // 第一幕仍有保护机制
    玩家生命值 = 1
    显示："<玩家名>感到一阵眩晕，但神秘的力量支撑着..."

    // 玩家仍可继续参与后续轮次
```
