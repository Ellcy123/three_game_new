# 06_BOSS战_死神

## 8.1 BOSS信息

### 基础属性

| 属性 | 值 |
|------|-----|
| 名称 | 死神 |
| 生命值 | 0（特殊机制） |
| 关卡序号 | 第三关（BOSS战/最终关卡） |
| 出战方式 | 三人团体出战 |
| 胜利条件 | 15轮内筹码超过 **1000** |
| 失败条件 | 15轮结束时筹码 ≤ 1000 或 筹码归零 |
| 失败结局 | 结局2：我也永远爱你（真结局） |

### 背景故事

> 引路人，带领你们来到这里的人。如果想逃出去，请打败他。

### 战斗开场文案

> 死神见你们居然挑战他，来了兴趣，决定与你们赌一盘，赌注是你们的生命。
>
> 若在 **15回合内** 赚取的生命值超过 **1000**，则胜利。
> 超过15回合或生命值归零则失败。

### 特殊说明

> **所有玩家生命值总和为筹码**，每轮请选择下注数量。
>
> 本关卡不区分个人生命值，三人共享筹码池。

## 8.2 核心机制

### 8.2.1 筹码系统

```
【初始筹码】
  = 三人当前生命值总和
  = 猫生命值 + 狗生命值 + 龟生命值

【筹码来源加成】
  • 商业鬼才：+30
  • 坦克的重要性：+20
  • 机械躯体（首次阵亡）：+20
  • 粒子光束炮：+200（一次性）
  • 其他生命值加成技能...

【示例计算】
  假设三人各剩10点生命值：
  初始筹码 = 10 + 10 + 10 = 30

  假设有商业鬼才(+30)和粒子光束炮(+200)：
  初始筹码 = 30 + 30 + 200 = 260
```

### 8.2.2 下注规则

```
【基本规则】
  • 每轮选择下注数量（0 到 当前筹码）
  • 下注后不可撤回
  • 胜利：筹码 += 下注 × (赔率 - 1)
    即：筹码 = 筹码 + 下注 × 赔率 - 下注 = 筹码 + 下注 × (赔率 - 1)
  • 失败：筹码 -= 下注

【赔率说明】
  赔率2：赢得下注金额的1倍（下注100，赢100）
  赔率5：赢得下注金额的4倍（下注100，赢400）
  赔率10：赢得下注金额的9倍（下注100，赢900）
  赔率20：赢得下注金额的19倍（下注100，赢1900）

【特殊轮次】
  第7轮、第8轮：无需下注，自动判定
```

### 8.2.3 胜负条件

```
【胜利条件】
  任意轮次结束时 筹码 > 1000

【失败条件】
  1. 第15轮结束时 筹码 ≤ 1000
  2. 任意轮次结束时 筹码 ≤ 0
  3. 第11轮投出4点（直接死亡）

【失败结局】
  触发 结局2：我也永远爱你
  （这是真结局，揭示世界观）
```

#### 【第10轮】三人轮流投掷

```

策略建议：
```

### 8.8.3 结算与检查函数

```typescript
function settleResult(
  state: DeathBattleState,
  bet: number,
  odds: number,
  isWin: boolean
): void {
  // 检查失败挽救
  if (!isWin) {
    isWin = checkFailureSave(state);
  }

  if (isWin) {
    let winAmount = bet * (odds - 1);

    // 最强忍者证明：胜利奖励翻倍
    if (hasSkill('最强忍者证明')) {
      winAmount *= 2;
      showMessage('最强忍者证明：奖励翻倍！');
    }

    state.chips += winAmount;
    showMessage(`胜利！+${winAmount}，当前筹码：${state.chips}`);
  } else {
    state.chips -= bet;
    showMessage(`失败...−${bet}，当前筹码：${state.chips}`);
  }
}

function checkFailureSave(state: DeathBattleState): boolean {
  // 灵魂互换手镯
  if (hasItem('灵魂互换手镯') && !itemUsed('灵魂互换手镯')) {
    if (playerChooseToUse('灵魂互换手镯')) {
      markItemUsed('灵魂互换手镯');
      showMessage('灵魂互换手镯：控制死神，本次失败不算！');
      return true;
    }
  }

  // 精准打击
  if (hasSkill('精准打击') && !skillUsed('精准打击') && state.chips >= 50) {
    if (playerChooseToUse('精准打击')) {
      state.chips -= 50;
      markSkillUsed('精准打击');
      showMessage('精准打击：消耗50筹码，重新判定！');
      // 重新投掷...
      return rerollAndCheck(state);
    }
  }

  // 超音速急行
  if (hasSkill('超音速急行')) {
    if (rollDice() <= 3) {
      showMessage('超音速急行：50%触发，本次失败不算！');
      return true;
    }
  }

  return false;
}

function checkGameEnd(state: DeathBattleState): void {
  // 胜利检查
  if (state.chips > 1000) {
    state.isGameOver = true;
    state.result = 'WIN';
    showMessage('🎉 筹码超过1000！战斗胜利！');
    return;
  }

  // 失败检查（筹码归零）
  if (state.chips <= 0) {
    // 检查复活技能
    if (checkRevivalSkills(state)) {
      return; // 复活成功，继续
    }

    state.isGameOver = true;
    state.result = 'LOSE';
    showMessage('💀 筹码归零...挑战失败');
  }
}

function checkRevivalSkills(state: DeathBattleState): boolean {
  // 机械躯体（首次）
  if (hasSkill('机械躯体') && !skillUsed('机械躯体')) {
    state.chips = 20;
    markSkillUsed('机械躯体');
    showMessage('机械躯体：复活！筹码+20');
    return true;
  }

  // 啸天
  if (hasSkill('啸天')) {
    if (rollDice() <= 3) {
      state.chips = 100;
      showMessage('啸天：复活！筹码+100');
      return true;
    }
  }

  // 第二引擎
  if (hasSkill('第二引擎')) {
    if (rollDice() <= 3) {
      state.chips = 20;
      showMessage('第二引擎：复活！筹码+20');
      return true;
    }
  }

  return false;
}

function canSaveFromDeath(state: DeathBattleState): boolean {
  // 第11轮投出4的特殊处理
  // 检查可用的挽救手段

  if (hasItem('灵魂互换手镯') && !itemUsed('灵魂互换手镯')) {
    markItemUsed('灵魂互换手镯');
    showMessage('灵魂互换手镯：逆转死亡判定！');
    return true;
  }

  if (hasSkill('精准打击') && !skillUsed('精准打击') && state.chips >= 50) {
    state.chips -= 50;
    markSkillUsed('精准打击');
    const newDice = rollDice();
    if (newDice !== 4) {
      showMessage(`精准打击：重新投掷，点数${newDice}，逃过一劫！`);
      return true;
    }
    showMessage(`精准打击：重新投掷，点数${newDice}...还是4！`);
  }

  if (hasSkill('超音速急行')) {
    if (rollDice() <= 3) {
      showMessage('超音速急行：闪避死亡！');
      return true;
    }
  }

  return false;
}

function rollDice(): number {
  return Math.floor(Math.random() * 6) + 1;
}
```
