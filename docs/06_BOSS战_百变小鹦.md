# 06_BOSS战_百变小鹦

## 7.1 BOSS信息

### 基础属性

| 属性 | 值 |
|------|-----|
| 名称 | 百变小鹦 |
| 生命值 | 4 |
| 关卡序号 | 第二关（BOSS战） |
| 出战方式 | 三人团体出战 |
| 胜利条件 | BOSS生命值归零 |
| 失败条件 | 三人全部阵亡 |
| 失败结局 | 结局1：疯人院 |

### 背景故事

> 掌握多国语言的天才鹦鹉，是这个世界的百鸟之王，哲学家，喜欢提出各种生活上的问题难倒敌人。

### 战斗开场文案

> 百变小鹦最看重的就是团队默契了，他会向你们提出一些问题，刁钻的小问题。
>
> 若玩家的选择相同，则小鹦生命值 **-1**（固定伤害，不参与加成）。
> 若不相同，全体玩家生命值 **-1**。

## 7.2 核心机制

### 7.2.1 默契测试规则

```
┌─────────────────────────────────────────────────────────┐
│                   系统出题（题库20题）                     │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│           三人同时作答（禁止任何形式的沟通）               │
│           玩家无法看到其他人的选择                        │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                      判定答案                            │
│  ┌─────────────────┐    ┌─────────────────┐            │
│  │ 三人答案相同     │    │ 答案不一致      │            │
│  │ BOSS生命值 -1   │    │ 全体玩家 -1    │            │
│  │ （固定伤害）     │    │                │            │
│  └─────────────────┘    └─────────────────┘            │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
                    下一题...
```

### 7.2.2 关键规则说明

| 规则 | 说明 |
|------|------|
| 禁止沟通 | 选择期间玩家不可交流、暗示、讨论 |
| 答案隐藏 | 玩家提交答案前无法看到其他人的选择 |
| 固定伤害 | 对BOSS的伤害固定为1，**不参与任何加成** |
| 团灭判定 | 三人生命值均归零时失败 |
| 题目顺序 | 可随机或按顺序出题 |

### 7.2.3 伤害计算

```
【对BOSS伤害】
  三人答案一致 → BOSS生命值 -1（固定）

  特例：【粒子炮】技能
    → 无视固定伤害限制，伤害额外 +1
    → 即答案一致时 BOSS生命值 -2

【对玩家伤害】
  答案不一致 → 全体玩家各 -1 生命值

  可被以下技能减免：
    → 舆论的力量（50%无效）
    → 最高龟格（50%减免）
    → 超音速急行（1/6命中）
    → 龟壳拆卸器（代替队友承伤）
    → 等...
```

### 7.2.4 胜负条件计算

```
【胜利条件】
  BOSS生命值 4 → 0
  需要答对 4 题（无粒子炮）
  需要答对 2 题（有粒子炮，每次-2）

【失败条件】
  三人全部阵亡

  假设三人各8点生命值，无任何减伤技能：
  → 连续答错 8 题，某人会阵亡
  → 实际上可能更早（取决于之前关卡消耗）

【极限情况】
  最少题数：2题（有粒子炮）
  最多题数：理论上无限（但题库20题，可循环或主持人发挥）
```

### 7.3.3 题目难度建议

```
【简单题】预期一致率 > 70%
  → 第19题（陷阱题，选项相同）
  → 第11题（河神，大多选C诚实）
  → 第13题（通常选蚊子，至少能飞）

【中等题】预期一致率 40-70%
  → 第5题（美食偏好，可能分歧）
  → 第8题（瞎蒙选项，各有习惯）
  → 第17题（奇偶数偏好）

【困难题】预期一致率 < 40%
  → 第2题（三个选项，分散概率）
  → 第9题（家庭立场，因人而异）
  → 第16题（MVP评选，主观性强）
```

### 7.3.4 出题策略建议

```
【渐进式】
  前2题：简单题，让玩家建立信心
  中间：中等题，制造紧张感
  后期：困难题，增加挑战

【随机式】
  完全随机出题
  增加不确定性

【自适应式】
  连续答对 → 出困难题
  连续答错 → 出简单题
  保持游戏节奏
```

### 7.4.2 各阶段详细说明

#### 阶段1：战斗开始

```
1. 显示BOSS信息
   - 名称：百变小鹦
   - 生命值：4
   - 机制说明

2. 检查跳关/免疫道具
   IF 使用【任意门】:
     跳转到指定关卡
   IF 使用【丘比特之箭】:
     本关卡免疫所有伤害（但仍需答题）

3. 显示当前玩家状态
   - 三人生命值
   - 持有技能列表
```

#### 阶段2：禁止沟通

```
【线上玩法】
  - 系统禁止玩家间私聊
  - 答案只能私聊发给系统/主持人
  - 违规判定：答题期间发送任何消息给其他玩家

【线下玩法方案1】
  - 主持人出题后，玩家私聊主持人发送答案
  - 禁止口头交流、眼神暗示

【线下玩法方案2】
  - 主持人出题后，玩家思考
  - 主持人倒计时（3-2-1）
  - 玩家同时举手表示答案
  - 举手方式：1指=A，2指=B，3指=C
```

#### 阶段3：出题

```
1. 从题库选择题目
   - 随机选择
   - 或按策略选择

2. 显示题目
   - 题目内容
   - 所有选项

3. 设置作答时限（可选）
   - 建议30秒
   - 超时自动随机选择
```

#### 阶段4：收集答案

```
1. 等待所有玩家提交
   - 记录每人选择
   - 隐藏其他人答案

2. 确认提交
   - 防止误操作
   - 提交后不可修改
```

#### 阶段5：揭示与判定

```
1. 同时揭示三人答案
   - 动画展示
   - 制造悬念

2. 判定结果
   IF 三人答案相同:
     damage = 1
     IF hasSkill('粒子炮'):
       damage += 1  // 无视固定伤害
     BOSS.hp -= damage
     显示"默契满分！"
   ELSE:
     FOR each player:
       applyDamage(player, 1)
     显示"默契不足..."

3. 更新状态
   - 刷新生命值显示
   - 播放相应动画
```

#### 阶段6：回合结束检查

```
1. 胜利检查
   IF BOSS.hp <= 0:
     显示"击败百变小鹦！"
     进入下一关（死神）

2. 失败检查
   IF 所有玩家阵亡:
     显示"团灭..."
     触发结局1（疯人院）

3. 继续检查
   IF 还有存活玩家 AND BOSS.hp > 0:
     进入下一题
```

### 7.5.5 本关无效的技能类型

```
【明确无效】
  - 所有对鼠鼠大王的伤害加成（喵喵叫、鼠类克星、泼水等）
  - 洞口选择类技能（借力打力、义眼等）
  - 出战限制类技能（狗的禁止出战在本关不适用）

【注意区分】
  - 通用减伤技能：有效
  - 通用免死技能：有效
  - 指定"第一关卡"的技能：无效
```

### 7.7.1 战斗主循环

```typescript
interface ParrotBattleState {
  bossHp: number;           // BOSS生命值（初始4）
  players: Player[];        // 玩家列表
  currentQuestion: number;  // 当前题号
  questionPool: Question[]; // 题库
  usedQuestions: number[];  // 已用题目
}

function startBossBattle_Parrot(): BattleResult {
  // 初始化
  const state: ParrotBattleState = {
    bossHp: 4,
    players: [cat, dog, turtle],
    currentQuestion: 0,
    questionPool: loadQuestionPool(),
    usedQuestions: []
  };

  // 战斗开始前检查
  if (hasItem('放大缩小灯') && playerChooseToUse('缩小')) {
    state.bossHp = Math.floor(state.bossHp * 0.5); // 4 → 2
    showMessage('放大缩小灯：BOSS生命值减半！');
  }

  // 免疫检查
  const isImmune = hasItem('丘比特之箭') && itemUsedThisBattle;

  // 进入禁止沟通模式
  enterNoCommunicationMode();

  // 主循环
  while (true) {
    // 选择题目
    const question = selectQuestion(state);
    state.currentQuestion++;

    // 显示题目
    displayQuestion(question);

    // 收集答案（带超时）
    const answers = collectAnswers(state.players, 30000); // 30秒超时

    // 揭示答案
    revealAnswers(answers);

    // 判定结果
    if (isAnswerConsistent(answers)) {
      // 答案一致，伤害BOSS
      let damage = 1;
      if (hasSkill('粒子炮')) {
        damage += 1; // 无视固定伤害限制
      }
      state.bossHp -= damage;
      showMessage(`默契满分！百变小鹦 -${damage}`);
    } else {
      // 答案不一致，伤害玩家
      if (!isImmune) {
        for (const player of state.players) {
          applyDamageToPlayer(player, 1, state);
        }
      }
      showMessage('默契不足...全体生命值 -1');
    }

    // 检查战斗结束
    if (state.bossHp <= 0) {
      exitNoCommunicationMode();
      return { result: 'WIN', nextStage: 'BOSS_3' };
    }

    if (allPlayersDead(state.players)) {
      exitNoCommunicationMode();
      return { result: 'LOSE', ending: 'ENDING_1' };
    }
  }
}
```

### 7.7.2 答案收集与判定

```typescript
interface Answer {
  player: Player;
  choice: string;  // 'A', 'B', 'C' 等
  timestamp: number;
}

function collectAnswers(players: Player[], timeout: number): Answer[] {
  const answers: Answer[] = [];
  const startTime = Date.now();

  // 并行等待所有玩家提交
  const promises = players.map(player => {
    return new Promise<Answer>((resolve) => {
      // 等待玩家输入或超时
      const choice = waitForPlayerInput(player, timeout);
      resolve({
        player,
        choice: choice || getRandomChoice(), // 超时随机选择
        timestamp: Date.now()
      });
    });
  });

  return Promise.all(promises);
}

function isAnswerConsistent(answers: Answer[]): boolean {
  if (answers.length === 0) return false;

  const firstChoice = answers[0].choice;
  return answers.every(a => a.choice === firstChoice);
}

function selectQuestion(state: ParrotBattleState): Question {
  // 过滤已用题目
  const availableQuestions = state.questionPool.filter(
    (_, index) => !state.usedQuestions.includes(index)
  );

  // 如果题目用完，重置（或主持人发挥）
  if (availableQuestions.length === 0) {
    state.usedQuestions = [];
    return selectQuestion(state);
  }

  // 随机选择
  const index = Math.floor(Math.random() * availableQuestions.length);
  const question = availableQuestions[index];

  // 记录已用
  state.usedQuestions.push(state.questionPool.indexOf(question));

  return question;
}
```

### 7.7.3 玩家伤害处理

```typescript
function applyDamageToPlayer(player: Player, baseDamage: number, state: ParrotBattleState): void {
  let damage = baseDamage;

  // 检查龟壳拆卸器（代替承伤）
  const turtle = state.players.find(p => p.type === 'TURTLE');
  if (turtle && hasItem('龟壳拆卸器', turtle) && player !== turtle) {
    if (playerChooseToUseShell(turtle, player)) {
      // 伤害转移给龟
      applyDamageToPlayer(turtle, damage, state);
      showMessage(`龟壳拆卸器：${turtle.name}代替${player.name}承受伤害！`);
      return;
    }
  }

  // 检查概率减免技能
  if (hasSkill('舆论的力量', player)) {
    if (rollDice() <= 3) {
      showMessage('舆论的力量：伤害无效化！');
      return;
    }
  }

  if (hasSkill('最高龟格', player)) {
    if (rollDice() <= 3) {
      showMessage('最高龟格：伤害减免！');
      return;
    }
  }

  if (hasSkill('超音速急行', player)) {
    if (rollDice() !== 1) {
      showMessage('超音速急行：闪避成功！');
      return;
    }
  }

  if (hasSkill('碧落黄泉', player)) {
    const roll = rollDice();
    if (roll <= 3) {
      player.hp += damage * 2;
      showMessage(`碧落黄泉：伤害翻倍吸收！生命值+${damage * 2}`);
      return;
    } else {
      state.bossHp -= damage;
      showMessage(`碧落黄泉：伤害转移给BOSS！`);
      return;
    }
  }

  // 应用伤害
  player.hp -= damage;

  // 检查阵亡
  if (player.hp <= 0) {
    handlePlayerDeath(player, state);
  }
}

function handlePlayerDeath(player: Player, state: ParrotBattleState): void {
  // 检查免死技能（与第一关相同）
  if (hasSkill('忍者勋章', player)) {
    if (rollDice() <= 3) {
      player.hp = 1;
      showMessage('忍者勋章：拒绝死亡！');
      return;
    }
  }

  if (hasItem('竹蜻蜓', player) && !player.usedBamboo) {
    player.hp = 1;
    player.usedBamboo = true;
    showMessage('竹蜻蜓：躲避致命伤害！');
    return;
  }

  if (hasSkill('第二引擎', player)) {
    if (rollDice() <= 3) {
      player.hp = 20;
      showMessage('第二引擎：复活！');
      return;
    }
  }

  if (hasSkill('妻子登场', player)) {
    let roll = rollDice();
    while (roll % 2 === 1) {
      player.hp += 2;
      roll = rollDice();
    }
    if (player.hp > 0) {
      showMessage('妻子登场：判定结束');
      return;
    }
  }

  // 确认阵亡
  player.isDead = true;
  showMessage(`${player.name} 阵亡！`);
}
```

## 7.9 主持人指南

### 7.9.1 线上玩法

```
【准备工作】
1. 创建私聊频道或使用系统私信功能
2. 准备题目列表
3. 确认禁止沟通规则

【流程】
1. 宣布进入禁止沟通模式
2. 在公共频道发布题目
3. 等待三人私信答案
4. 在公共频道公布三人答案
5. 宣布判定结果
6. 重复直到战斗结束

【注意事项】
- 监控玩家是否违规沟通
- 设置合理的答题时限
- 保持公平公正
```

### 7.9.2 线下玩法

```
【方案A：私信答案】
1. 出题后，玩家用手机私信主持人答案
2. 主持人收齐后公布
3. 优点：严格防作弊
4. 缺点：流程较慢

【方案B：举手投票】
1. 出题后，玩家思考
2. 主持人倒计时"3-2-1"
3. 玩家同时举手表示答案
   - 1指 = A
   - 2指 = B
   - 3指 = C
4. 优点：快速有趣
5. 缺点：需要玩家自律

【方案C：纸牌答题】
1. 每人发ABC三张牌
2. 出题后，玩家选牌扣在桌上
3. 主持人倒计时后同时翻开
4. 优点：公平且有仪式感
```

### 7.9.3 题目扩展建议

```
【自定义题目原则】
1. 选项数量2-3个为宜
2. 避免知识性问题（答案唯一）
3. 偏向性格/偏好类问题
4. 可针对玩家关系设计
5. 适当加入幽默元素

【示例自定义题】
- "你们三个谁最可能迟到？"
- "如果只能带一样东西去荒岛，你选？"
- "你认为谁最适合当队长？"
```
